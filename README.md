# Пользовательский хук useJsonFetch (Hooks & Context)

Учебный проект на **React** и **TypeScript**, демонстрирующий реализацию и использование пользовательского хука `useJsonFetch` для автоматизации HTTP-запросов.

## 🚀 Функциональность

* **Кастомный хук `useJsonFetch(url, options)`**:
  * Возвращает кортеж `[data, loading, error]`.
  * Автоматически обрабатывает статусы ответа сервера (`response.ok`).
  * Безопасно отслеживает состояние размонтирования компонента.
* **Демонстрация работы**:
  * Успешный запрос с выводом форматированного JSON.
  * Запрос с ошибкой (404 / сетевой сбой) с понятной индикацией.
  * Индикатор загрузки во время ожидания ответа.

## 🛠 Технологии

* **React 18 / 19** (`useState`, `useEffect`, Custom Hooks)
* **TypeScript**
* **Vite**
* **Fetch API**
